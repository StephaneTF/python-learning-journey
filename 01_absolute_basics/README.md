# Absolute Basics

Introductory Python exercises covering fundamental syntax, variables, data types, operators, and basic input/output.

## Concepts Practiced

- Variables and data types
- Strings and numeric values
- Basic arithmetic operators
- User input and type conversion
- Formatted output with f-strings
- Comparison and modulo operators
- Basic conditional statements

## Exercises

| Exercise | Description |
|---|---|
| `block_letters.py` | Uses print statements to create block-letter output |
| `receipt.py` | Calculates a customer purchase total and sales tax |
| `odd_or_even.py` | Uses user input and modulo operations to evaluate numbers |
| `sal_shipping.py` | Calculates shipping costs using basic conditional logic |
| `personal_info.py` | Collects and displays basic user information |
| `temperature_converter.py` | Converts Celsius temperatures to Fahrenheit |
| `bill_calculator.py` | Calculates subtotal, tax, and final purchase total |
| `seconds_converter.py` | Converts seconds into minutes and remaining seconds |
