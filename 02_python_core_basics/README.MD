# Python Core Basics

Python exercises focused on strengthening core programming concepts through functions, loops, conditionals, collections, string manipulation, and basic problem-solving.

## Concepts Practiced

- Conditional statements
- `for` and `while` loops
- Functions, parameters, and return values
- Lists and list comprehensions
- Dictionaries and dictionary comprehensions
- Sets
- String manipulation and slicing
- User input and input validation
- Random number generation
- Searching and basic algorithms
- Nested data structures
- Combining multiple Python concepts

## Exercises

| Exercise | Description |
|---|---|
| `dico_comprehension.py` | Builds and modifies dictionaries using dictionary comprehension and nested dictionaries |
| `list_comprehension.py` | Filters user-provided numbers using list comprehension |
| `magic_8-ball.py` | Uses conditionals and random numbers to simulate a Magic 8-Ball |
| `max_three.py` | Uses a function and conditional logic to find the largest of three numbers |
| `palindrome_lists.py` | Checks whether a string is a palindrome using slicing |
| `remove_duplicate_list.py` | Removes duplicate elements from a list using loops and sets |
| `thread_shed.py` | Cleans and processes sales data using strings, lists, loops, and functions |
| `scrable.py` | Calculates Scrabble scores using dictionaries, loops, and functions |
| `rock_paper_scissors.py` | Implements an interactive Rock-Paper-Scissors game with input validation |
| `element_search.py` | Implements binary search to determine whether an element exists in an ordered list |
| `reverse_word_order.py` | Reverses the order of words in user-provided text using functions and slicing |
| `fibonacci.py` | Generates a Fibonacci sequence using functions, loops, lists, and input validation |
| `bordless_tourist.py` | Recommends tourist attractions based on destination and traveler interests |
